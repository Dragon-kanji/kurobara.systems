# Security policy

Kurobara is a pre-release project and does not currently promise a security
support window or response time.

Report website vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/Dragon-kanji/kurobara.systems/security/advisories/new).
Do not disclose a vulnerability in a public issue or pull request.

Include the affected commit, minimal reproduction steps, impact, testing
boundaries, and redacted evidence. Never include credentials, personal data,
production dumps, or data you are not authorized to share.

Only test systems and data you own or are explicitly authorized to use. Avoid
service disruption, unauthorized cost, persistence, mass scanning, and access
beyond the minimal proof.
